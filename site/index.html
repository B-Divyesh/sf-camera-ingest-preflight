INSPECTION GRID / 07 CHECKS

A contact sheet for failure modes.

Every regular file receives a SHA-256 fingerprint and a conservative, explainable verdict for your selected downstream profile.

  1. 01Format gate

    Accepted, version-sensitive, or rejected for Generic, PhotoPrism, and Lightroom profiles.

  2. 02RAW preview

    Finds a bounded embedded JPEG so the library has something fast and faithful to display.

  3. 03360° projection

    Reads GPano XMP, near-2:1 dimensions, and cautious filename clues without pretending to stitch.

  4. 04Orientation

    Translates EXIF values 1–8 and flags invalid rotation or mirror values.

  5. 05Duplicate bytes

    Hashes the whole file, not a filename, to surface card copies and burst-folder repeats.

  6. 06Camera identity

    Calls out absent, partial, or garbled make/model metadata before indexing.

  7. 07Location privacy

    Reports GPS presence while redacting coordinates unless you explicitly include them.

INSTALLATION / RUST 1.85+

One binary. One honest exit code.

Exit 0 means import-ready, 1 means review the findings, and 2 means the folder could not be scanned. Symlinks are never followed.
